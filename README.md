### How I ship ML
```mermaid
flowchart LR
  A[Identify the problem] --> B[Observe existing workflow]
  B --> C[Test workflow bottlenecks]
  C --> D[Data / signals]
  D --> E[Clean + features]
  E --> F[Train / eval]
  F --> G[Serve API]
  G --> H[Monitor + retrain]
  H -.-> C
```
